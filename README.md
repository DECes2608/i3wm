## 📦 Kurulum

### Düz kurulum


```bash
git clone https://github.com/DECes2608/i3wm
cd i3wm
cp -r i3 .config/
cp -r rofi .config/
cp -r polybar .config/
cp -r kitty .config/
cp -r dunst .config/
```


### Basit kurulum (sadece void için)

```bash
git clone https://github.com/DECes2608/i3wm
cd i3wm && bash install.sh
```
